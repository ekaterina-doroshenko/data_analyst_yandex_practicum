# Анализ внутриигровых покупок в проекте "Секреты темнолесья"

## Описание проекта: 

Команда игры планирует привлекать платящих игроков и продвигать покупку предметов с помощью рекламы. Необходимо выяснить, какая доля игроков покупает 
внутриигровую валюту за реальные деньги и есть ли зависимость доли платящих игроков от персонажа; детально изучить, как происходит покупка предметов внутри игры.

## Что выполнено в рамках проекта:

**Часть 1. Исследовательский анализ данных:**
- доля платящих пользователей по всем данным и в разрезе персонажа;
- статистические показатели;
- рейтинг популярности предметов.

**Часть 2. Ad-hoc задача:**
- зависимость активности игроков от персонажа.
